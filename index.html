Skip List vs AVL Tree

Aim: To implement a skip list and an AVL tree as ordered dictionaries and compare their empirical performance (time and key comparisons) for insert, search and delete on large random workloads.

Inputs

For each n: generate n distinct random keys in [1, 10n), time n inserts, n/2 searches and n/2 deletes on both structures, and count key comparisons per operation.

Algorithm (pseudocode) and complexity 
SkipList-Search(L, key)
  x ← L.header
  for i ← L.level downto 0
      while x.forward[i] ≠ NIL and x.forward[i].key < key: x ← x.forward[i]
  x ← x.forward[0]
  return x.value if x ≠ NIL and x.key = key else NIL

Random-Level(p, MaxLevel)
  lvl ← 0; while Random() < p and lvl < MaxLevel: lvl ← lvl + 1
  return lvl

SkipList-Insert / Delete: find update[] predecessors as in Search,
  then splice the node in (levels 0..lvl) or out, and shrink L.level.

AVL-Insert(T, key): BST insert, then Rebalance on the way up
Rebalance(z): update height, b = h(left) − h(right)
  b >  1 → (LR: rotate left child left) then rotate right
  b < −1 → (RL: rotate right child right) then rotate left
Operation                        Time                       Space
Skip list search/insert/delete   O(log n) expected, O(n) worst   O(n) expected (~2n pointers)
AVL search/insert/delete         O(log n) worst case        O(n)
Skip list range query            O(log n + k)               O(k) output
